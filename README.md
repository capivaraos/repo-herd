# repo-herd

Repositório de atualizações assinado do **CapivaraOS Herd**.

- **Índice (metadados):** servido por este GitHub Pages (`repo-herd.capivaraos.org`).
- **Pacotes (.rpm):** anexos de GitHub Releases deste mesmo repositório (resolvidos via `xml:base` no índice).
- **Confiança:** vem da assinatura GPG (chave pública: `RPM-GPG-KEY-capivaraos-herd`), não do host. `gpgcheck` + `repo_gpgcheck` rejeitam qualquer pacote ou índice não assinado pela chave do Herd.

A chave privada fica offline. Ver a documentação do projeto para o fluxo de publicação.
